# Portofolio_saya

## Isi folder
- `index.html` — struktur halaman portfolio
- `style.css` — desain dan responsive layout
- `script.js` — interaksi menu mobile dan tahun footer

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `portfolio_naufal`.
3. Klik dua kali `index.html`, atau buka folder melalui VS Code lalu jalankan dengan Live Server.

## Sebelum dikumpulkan
- Ganti `emailkamu@example.com` di `index.html` dengan email aktif.
- Periksa kembali nama, program studi, daftar skill, dan deskripsi proyek.
- Jika ada, tambahkan foto profil asli untuk mengganti avatar inisial NY.
- Pastikan semua konten proyek sesuai dengan proyek yang benar-benar pernah dibuat/dikerjakan.

## Aturan penamaan CSS
Selector CSS dan ID/kelas HTML menggunakan awalan `naufal_` sebagai kombinasi nama mahasiswa.

## Hosting gratis dengan GitHub Pages
1. Login ke https://github.com
2. Klik **New repository**. Beri nama `portfolio-naufal`, pilih **Public**, lalu buat repository.
3. Upload tiga file (`index.html`, `style.css`, `script.js`) dari folder ini ke repository. Pastikan `index.html` berada di root repository.
4. Buka **Settings → Pages**.
5. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
7. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website, biasanya `https://username.github.io/portfolio-naufal/`.
8. Salin link tersebut untuk dikumpulkan di Google Classroom.

Catatan: alamat website memakai username GitHub masing-masing, jadi jangan menyalin contoh URL secara mentah.
